# Fotoğraf albümü
Orijinaller proje kökündeki fotoğraflar/ klasöründedir ve değiştirilmez.
`npm run photos:prepare` web kopyalarını album/ altında ve manifesti data/photos.json dosyasında oluşturur.
Başlık/tarih düzenlemesi: data/photos.json. Yeniden üretim elle yapılan manifest değişikliklerini üzerine yazar.
